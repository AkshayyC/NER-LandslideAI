# NER-LandslideAI

AI-powered landslide risk monitoring and early-warning
system for Northeast India.

## Objective

NER-LandslideAI aims to estimate landslide risk using
environmental, terrain, rainfall and historical landslide
information.

## Core Pipeline

Data Collection
        ↓
Data Processing
        ↓
Feature Engineering
        ↓
Machine Learning
        ↓
Risk Scoring
        ↓
Early Warning
        ↓
Dashboard

## Target Region

Northeastern Region of India:

- Arunachal Pradesh
- Assam
- Manipur
- Meghalaya
- Mizoram
- Nagaland
- Sikkim
- Tripura

## Project Status

🚧 Under development

## Disclaimer

This is a research/hackathon prototype and is not an
operational emergency-warning system.
